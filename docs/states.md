## Mock exam sizing
- Each mock exam has the same number of questions as the state's real knowledge test (PA: 18). If the state publishes no count, use 25 and say in the book that the state does not publish a count.
- Where the test has separate parts (GA, VA), each mock mirrors the parts.
- Mocks draw from the bank: about 60 percent core, 40 percent state questions, no question repeated from the chapter quizzes.
